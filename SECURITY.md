# Security Policy

## Supported Versions

| Version | Supported    |
| ------- | ------------ |
| latest  | ✅ Supported |

Older versions are not supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

**Do not** file a public issue. Instead, send an email to <baneeishaque@gmail.com>.

We will acknowledge receipt within 48 hours and provide
a timeline for a fix.

## Disclosure Policy

When a vulnerability is reported:

1. We confirm receipt and begin investigation.
2. We develop and test a fix.
3. We release a security patch and disclose the vulnerability.

We follow coordinated disclosure to protect users.
